# MarkEdit Windows launcher

Installs and opens the verified Windows portable release. Requires Windows x64 and Node.js 20+ when run through npx. No runtime dependencies.

Run `node cli.cjs --help` for options. The bundled PowerShell installer verifies the ZIP against the release SHA-256 manifest before installing under the user profile.
